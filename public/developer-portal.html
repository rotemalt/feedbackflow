Developer Introduction

Architectural design patterns and low-overhead COSS architecture

Welcome to FeedbackFlow

FeedbackFlow is a high-performance, open-source alternative to expensive customer feedback widgets and roadmap platforms. Instead of relying on heavy pre-compilers or large enterprise stacks, FeedbackFlow adopts a **Zero-Bloat Product Architecture**:

  • Zero-Dependency Core: Runs with just standard Express, SQLite3, CORS, and JWT signatures. Persists into a single local database file.
  • Permissive Dual Licensing: The administrative dashboard console is licensed under GNU AGPLv3, while the floating injection client widget is 100% MIT, letting you inject it into proprietary, closed-source SaaS products without copyleft risks.
  • Shadow-DOM Styling Isolation: Leveraging Shadow-DOM isolation inside widget.js guarantees that parent CSS rules do not break the widget structure, nor do the widget's themes bleed into your product.

Widget Embedding Guide

Visual configuration playground and automatic script generators

Embedding Script

To embed the FeedbackFlow board inside any client page, simply copy and paste the compiled script block before the closing </body> tag of your HTML. Use the **Live Visual Customizer Sandbox** in the right-hand panel to play with themes, customize titles, and see the sandbox widget render in real-time. 

<!-- Embed Floating Widget -->
<script src="http://localhost:4000/widget.js" data-project-key="web-app-key"></script>
import Script from 'next/script';

export default function AppLayout({ children }) {
  return (
    <>
      {children}
      <Script 
        src="http://localhost:4000/widget.js" 
        data-project-key="web-app-key"
        strategy="lazyOnload"
      />
    </>
  );
}
<!-- Vue Component -->
<template>
  <div>
    <router-view />
  </div>
</template>

<script>
export default {
  mounted() {
    const script = document.createElement('script');
    script.src = "http://localhost:4000/widget.js";
    script.setAttribute('data-project-key', 'web-app-key');
    document.body.appendChild(script);
  }
}
</script>

🚀 Transitioning to Production (SaaS Integration)

When you move FeedbackFlow from local development to your live production SaaS, the transition is completely seamless:

  • Dynamic Host Auto-Detection: The script widget.js automatically parses the domain it is loaded from (via document.currentScript.src). If you host your assets on GitHub Pages (e.g. https://rotemalt.github.io/feedbackflow/public/widget.js) and embed the script using that URL, the widget automatically routes all API requests (like upvotes, submissions, comments) to your backend host database—no hardcoded code edits required!
  • HTTPS Secured Sockets: Modern browsers require widgets embedded inside secured SaaS apps to load over HTTPS. Configure Nginx, Cloudflare SSL, or secure hosting parameters for your production port 4000.
  • Persistent Volume: Map a persistent docker volume to /usr/src/app/data on your VPS or cloud container host to ensure your SQLite settings and cards are never lost during restarts.

User Identification API

Sync verified, signed-in user profiles directly into the widget context

Bypassing Anonymity

By default, users submit feedback anonymously or input their names manually. However, if a customer is already signed into your SaaS platform, you can pass their verified credentials directly to the widget.

This **automatically attributes incoming requests to their account, logs them in our database, and completely hides the Name and Email forms** inside the client widget panel!

Defining Context

Simply define the window.FeedbackFlow global object on your parent page before loading the widget script: 

<script>
    window.FeedbackFlow = {
        email: "sarah.jenkins@designco.com",
        name: "Sarah Jenkins"
    };
</script>
<script src="http://localhost:4000/widget.js" data-project-key="web-app-key"></script>

Use the visual toggles in the **Sandbox panel (right)** to enable User pre-fill and see the widget hide forms and auto-prefill titles instantly!

REST API Blueprint Reference

Complete backend API models with interactive, live-fetching REST Client

GET /api/widget-config?apiKey=YOUR_API_KEY

Retrieves workspace branding configurations (theme color, welcome title). Triggered on widget boot.

GET /api/feedback?projectId=ID

Retrieves existing feedback cards for a project, sorted by vote counts. Renders the public boards.

POST /api/feedback

Submits a new customer feedback card. AI Agents process this dynamically.

GET /api/feedback/:id/comments

Retrieves discussion comment threads for a specific feedback ticket.

Docker Production Deploy

Deploy the complete B2B SaaS service suite in under 5 seconds

docker-compose.yml

Deploy on your server with persistent SQLite volumes, custom ports, and dynamic JWT secrets: 

version: '3.8'

services:
  feedbackflow:
    container_name: feedbackflow
    image: node:18-alpine
    working_dir: /usr/src/app
    volumes:
      - .:/usr/src/app
    ports:
      - "4000:4000"
    environment:
      - PORT=4000
      - NODE_ENV=production
      - JWT_SECRET=change-this-to-a-secure-key-in-production
      - GEMINI_API_KEY=YOUR_GOOGLE_GEMINI_KEY
    command: sh -c "npm install && npm start"
    restart: unless-stopped

Launch Command

# Startup containers
docker compose up -d

# Inspect startup database migrations and logs
docker compose logs -f
